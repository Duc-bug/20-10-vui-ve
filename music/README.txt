HƯỚNG DẪN THÊM NHẠC NỀN
========================

Bước 1: Tìm bài nhạc bạn muốn
- Vào YouTube và tìm bài nhạc yêu thích
- Hoặc dùng file nhạc có sẵn trên máy (.mp3)

Bước 2: Tải nhạc về (nếu từ YouTube)
- Vào trang: https://ytmp3.nu/
- Hoặc: https://y2mate.com/
- Dán link YouTube vào và tải về dạng MP3

Bước 3: Đổi tên file nhạc
- Đổi tên file nhạc thành: background.mp3
- Copy vào thư mục này (music/)

Bước 4: Test thử
- Mở file index.html trên trình duyệt
- Click vào hoa hồng, nhạc sẽ tự động phát
- Click vào nút nhạc ở góc dưới bên phải để bật/tắt

GỢI Ý MỘT SỐ BÀI NHẠC HAY:
- "Purpose" - Taeyeon
- "Because of You" - Taeyeon  
- "Spring Day" - BTS
- "Người Lạ Ơi" - Superbrothers
- "Hoa Cỏ Lau" - Phạm Lịch
- "Cô Gái M52" - Huy R
- "See Tình" - Hoàng Thùy Linh

Lưu ý:
- File nhạc phải là định dạng .mp3
- Tên file phải là: background.mp3
- Nếu muốn đổi tên khác, sửa trong file index.html dòng:
  <source src="./music/TÊN_FILE_CỦA_BẠN.mp3" type="audio/mpeg">
